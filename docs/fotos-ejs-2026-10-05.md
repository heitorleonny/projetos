## Ajuste aplicado

`EjLogo` aceita agora URLs HTTPS sem credenciais, descarta esquemas inseguros e endereços locais explícitos, usa `referrerPolicy="no-referrer"` e mantém o fallback de iniciais. **Caminhos locais iniciados por `/` são preservados**, pois o campo textual e o componente anterior os aceitavam; URLs com `//`, travessia `..`, barras invertidas ou caracteres de controle são recusadas, inclusive quando codificados. Caminhos relativos à rota (`logos/ej.png`) não são usados. A imagem usa `object-contain`, para não cortar logos. Nenhuma URL é buscada pelo servidor para validação, e nenhum nome de EJ escolhe imagem de outra federação. A validação sintática não garante disponibilidade, propriedade ou resolução DNS do domínio; `onError` cuida de imagem indisponível.

## Reprodução sem expor dados

Rodar a partir de `/Users/heitor/Documents/TCC`, com Python que possua `openpyxl`:

```python
from pathlib import Path
import openpyxl

for arquivo in sorted(Path("dados").glob("*.xlsx")):
    livro = openpyxl.load_workbook(arquivo, read_only=True, data_only=True)
    for aba in livro:
        cabecalho = next(aba.values, ())
        fotos = [coluna for coluna in cabecalho if isinstance(coluna, str)
                 and any(termo in coluna.casefold() for termo in ("foto", "logo", "imagem"))]
        print(arquivo.name, aba.title, aba.max_row - 1, aba.max_column, fotos)
    livro.close()
```
